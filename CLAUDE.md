## Agent skills

### Issue tracker

Code issues live in the owning repo's GitHub Issues (backend, frontend, thinking-loop); this home repo's GitHub Issues hold cross-repo tracking issues that reference them. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
